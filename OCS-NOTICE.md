# Open Coding Society design grammar attribution

XCare's `_sass/components/_ocs-grammar.scss` independently implements the public Open Coding Society button, card, grid, and theme-token grammar for this site. The implementation is adapted for XCare's existing Sass and Jekyll structure; XCare's branding, healthcare content, page behavior, and assets remain XCare's. No Open Coding Society logo, imagery, or page copy is included.
